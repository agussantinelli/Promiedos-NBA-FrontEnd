# 🔄 Promiedos-NBA — README Auto-Sync

Directrices para mantener el README sincronizado con el estado real del proyecto.

## 📏 Reglas

1. **Estructura del Proyecto**:
   - **CUÁNDO**: Cada vez que creés, mováis o eliminéis un archivo `.ts`, `.svelte`, `.css` o un directorio dentro de `src/`.
   - **QUÉ HACER**: Actualizá la sección `📁 Estructura del Proyecto` en el `README.md`.

2. **Stack Tecnológico**:
   - **CUÁNDO**: Si se incorpora una nueva dependencia relevante (ej. una librería de gráficos, una herramienta de build).
   - **QUÉ HACER**: Agregá una fila en la tabla `🧱 Stack tecnológico`.

3. **Comandos pnpm**:
   - **CUÁNDO**: Si se agrega un nuevo script en `package.json`.
   - **QUÉ HACER**: Agregá una fila en la tabla `💻 Comandos pnpm disponibles`.
